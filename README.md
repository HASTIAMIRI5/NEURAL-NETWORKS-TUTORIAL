## 📖 About

This repository is a structured curriculum for learning neural networks, covering both theory and implementation. Each topic includes:

- 📐 Mathematical foundations and intuition
- 💻 From-scratch implementations with NumPy
- 🚀 Real-world implementations with PyTorch and TensorFlow
- 📓 Interactive notebooks for learning and experimentation
- 📊 Visualizations and practical examples

Whether you are a beginner or looking to strengthen your understanding, this repo guides you through every core concept: neurons, layers, activations, losses, optimization, CNNs, RNNs, transformers, and GANs.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/HASTIAMIRI5/NEURAL-NETWORKS-TUTORIAL.git
cd NEURAL-NETWORKS-TUTORIAL
```

2. Create and activate a virtual environment:

```bash
python -m venv venv
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start Jupyter and explore the notebooks:

```bash
jupyter notebook
```

### ☁️ Run in Google Colab

Each notebook can be opened directly in Google Colab for quick experimentation without local installation.
