📖 About

This repository is a complete, structured curriculum for learning neural networks. Every concept is explained with:

· 📐 Mathematical foundations — the theory behind the code
· 💻 From-scratch implementations — NumPy implementations to understand internals
· 🚀 Framework implementations — PyTorch & TensorFlow for real-world usage
· 📓 Interactive notebooks — runnable in Google Colab
· 📊 Visualizations — plots, decision boundaries, training curves

Whether you're a beginner or looking to deepen your understanding, this repo walks you through every layer, loss function, and optimization step.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/neural-networks-tutorial.git
cd neural-networks-tutorial
2. Create a virtual environment

python -m venv venv
source venv/bin/activate       # Linux / macOS
venv\Scripts\activate          # Windows
3. Install dependencies

pip install -r requirements.txt
4. Run a notebook

jupyter notebook
☁️ Run in Google Colab

Each notebook includes a "Open in Colab" badge at the top — no installation needed!
